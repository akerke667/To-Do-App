# Тапсырмалар менеджері (To-Do App)

PHP және MySQL көмегімен әзірленген веб-қосымша (жеке жоба).

## Жоба туралы
Бұл платформа қолданушыларға өз күнделікті тапсырмаларын тіркеп, категориялар бойынша бөлуге, орындалу күйін өзгертуге және іздеуге мүмкіндік береді.

## Негізгі мүмкіндіктер
- Пайдаланушыларды тіркеу және жүйеге кіру (Authentication & Authorization).
- Тапсырмаларға толық CRUD операцияларын жасау (Қосу, Көру, Мәртебесін өзгерту, Жою).
- Категориялар бойынша бөлу (Жеке, Оқу, Жұмыс).
- Тапсырма атауы бойынша іздеу жүйесі.
- Қауіпсіздік: Құпия сөздерді шифрлау (password_hash) және PDO Prepared Statements (SQL Injection-ге қарсы).

## Технологиялар стекі
- **Backend:** PHP, PDO
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, Bootstrap 5
- **Tools:** VS Code, XAMPP / OpenServer, Git & GitHub

## Дерекқорды орнату (Database Setup)
1. MySQL серверінде `todo_db` атты дерекқор құрыңыз.
2. Жобадағы SQL скриптерін орындап, `users`, `categories`, `tasks` кестелерін жасаңыз.
